# Кибер-квест "Проект: Карамель"

Квест для детей 11–14 лет. 3 отдела (Полиция, ФБР, Кибербезопасность), по 20 этапов в каждом. Ориентировочное время прохождения — 2 часа. Прогресс сохраняется в localStorage.

## Как развернуть на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на [GitHub](https://github.com/).
2. Создайте новый репозиторий (например, `cyber-quest`), сделайте его **Public**.
3. Загрузите в репозиторий файлы: `index.html`, `police.html`, `fbi.html`, `cyber.html`, `style.css`.
4. Перейдите в **Settings** → **Pages**.
5. В разделе **Build and deployment**:
   - Source: **Deploy from a branch**.
   - Branch: **main** (или `master`), папка **/ (root)**.
6. Нажмите **Save**.
7. Через 1–2 минуты сайт будет доступен по ссылке вида:
   `https://ваш_логин.github.io/cyber-quest/`
8. Ссылки для отделов:
   - Полиция: `https://ваш_логин.github.io/cyber-quest/police.html`
   - ФБР: `https://ваш_логин.github.io/cyber-quest/fbi.html`
   - Кибербезопасность: `https://ваш_логин.github.io/cyber-quest/cyber.html`

## Структура квеста

- **20 этапов** в каждом отделе.
- **Перекрёстные коды** (Этап 2):
  - Полиция выдаёт для ФБР → `FBI-2026`
  - ФБР выдаёт для Кибербезопасности → `CYBER-55`
  - Кибербезопасность выдаёт для Полиции → `POLICE-99`
- **Этап 3** — «подставная биометрия»: система требует подтвердить личность начальника; дети сами догадываются сгенерировать фейк (видео / аудио / текст) и прикрепить.
- **Этап 19** — выдача фрагмента рецепта двоичным кодом (крупная надпись «ОДНА ЧАСТЬ ПАЗЛА ПОЛУЧЕНА…»).
- **Этап 20** — финал, ответ `Дана Сергеевна`.

## Важно

- Прогресс сохраняется в браузере (localStorage, ключи `*_state_v2`, `*_timer_v2`). Дети должны проходить квест в **одном и том же браузере**.
- Пароль шефа для экстренной выдачи ответа: **1357** (после 10 неудачных попыток).
- Подсказка появляется после 6 неудачных попыток.
- Таймер: 2:00:00, не сбрасывается при обновлении.
- Проверка прикрепляемых файлов не выполняется — принимается любой файл. Коды доступа проверяются строго.
- Фотографии в досье сейчас — emoji-заглушки. Для реальных фото замените `emoji` на `<img src="...">` в массиве `dossierData`.
