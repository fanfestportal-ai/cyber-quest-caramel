# Кибер-квест "Проект: Карамель"

## Как развернуть на GitHub Pages (бесплатно)

1. Зарегистрируйтесь на [GitHub](https://github.com/).
2. Создайте новый репозиторий (например, `cyber-quest`), сделайте его **Public**.
3. Загрузите в репозиторий 4 файла: `index.html`, `police.html`, `fbi.html`, `cyber.html`.
4. Перейдите в **Settings** (Настройки) репозитория.
5. В левом меню выберите **Pages**.
6. В разделе **Build and deployment**:
   - Source: **Deploy from a branch**.
   - Branch: **main** (или `master`), папка **/ (root)**.
7. Нажмите **Save**.
8. Через 1–2 минуты сайт будет доступен по ссылке вида:
   `https://ваш_логин.github.io/cyber-quest/`
9. Ссылки для отделов:
   - Полиция: `https://ваш_логин.github.io/cyber-quest/police.html`
   - ФБР: `https://ваш_логин.github.io/cyber-quest/fbi.html`
   - Кибербезопасность: `https://ваш_логин.github.io/cyber-quest/cyber.html`

## Важно!
- Прогресс сохраняется в браузере (localStorage). Дети должны проходить квест в **одном и том же браузере**.
- Пароль шефа для экстренной выдачи ответа: **1357**.
- Таймер запускается автоматически при первом открытии и не сбрасывается.
